2. Tableaux de données

Un data.frame est un tableau de données, comparable à une feuille Excel. En sciences expérimentales, chaque ligne correspond généralement à un échantillon, une mesure ou une observation ; chaque colonne représente une variable ou une information sur cette observation.

echantillon pH masse valide
A01 6.8 2.45 TRUE
A02 7.2 2.51 TRUE
A03 5.9 2.48 FALSE
A04 7.1 2.53 TRUE

Ce tableau contient quatre observations et quatre variables. La première colonne est textuelle (character), les deux suivantes sont numériques (numeric) et la dernière est logique (logical). Chaque colonne est généralement un vecteur d’un même type, mais les colonnes peuvent avoir des types différents. Elles ont toutes le même nombre de lignes. Les valeurs manquantes peuvent être représentées par NA.

Construire et explorer un tableau

data.frame() assemble les vecteurs en colonnes nommées. Les éléments de même position forment une ligne. Utilisez de préférence des vecteurs de même longueur lors de la construction.

Fonction Rôle
str(mesures) Structure et classes des colonnes
dim(mesures) Dimensions : lignes, puis colonnes
nrow(mesures) Nombre de lignes
ncol(mesures) Nombre de colonnes
names(mesures) Noms des colonnes
head(mesures) Premières lignes
summary(mesures) Résumé des colonnes

Extraire des lignes, colonnes ou valeurs

La syntaxe générale est tableau[ligne, colonne]. Les indices commencent à 1. Laisser une position vide signifie sélectionner toutes les lignes ou toutes les colonnes correspondantes. $ permet d’extraire une colonne par son nom sous forme de vecteur.

mesures$pH est un vecteur numérique ; mesures["pH"] est encore un data.frame à une colonne. Cette distinction est importante pour choisir la bonne fonction R.

À vous de jouer — exploration (entraînement)

À partir du tableau analyse fourni, affichez sa structure, son nombre de lignes, la masse du deuxième échantillon puis la moyenne de la colonne masse.

Utilisez str(), nrow(), les crochets et mean().

str(analyse)
nrow(analyse)
analyse[2, "masse"]
mean(analyse$masse)

4. Sélection et filtrage

Dans d[lignes, colonnes], une condition logique sélectionne les lignes. Une position vide signifie toutes les lignes ou colonnes.

Exemple à manipuler

aggregate() calcule un résumé par groupe avec la notation variable ~ groupe.

Exemple à manipuler
